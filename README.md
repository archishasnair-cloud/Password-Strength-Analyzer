# Password-Strength-Analyzer

A simple Python project that evaluates the strength of user-entered passwords based on security factors such as length, uppercase letters, lowercase letters, numbers, special characters, and password reuse.

## Features

* Password strength classification (Weak, Medium, Strong)
* Checks password complexity
* Suggests improvements for weak passwords
* Generates a strong password recommendation
* Prevents reuse of old passwords

## Technologies Used

* Python
* Regular Expressions (`re`)
* Random Module (`random`)

## How to Run

```bash
python password_analyzer.py
```

## Learning Outcome

Understanding password security principles and implementing basic password validation techniques in Python.
